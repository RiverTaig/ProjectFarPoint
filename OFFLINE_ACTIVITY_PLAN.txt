Parameter contract:
 - t: registered short trail code; TA = Te Araroa.
 - p: project path; V = Voyager, F = Far Point Trail.
 - dt: hike start time, YYYYMMDDTHHMM, using the registered trail's local
   timezone. TA uses Pacific/Auckland; resolve daylight saving from that zone.
   Ambiguous or nonexistent local times require correction/clarification.
 - s and e: start/end coordinates, decimal longitude,latitude in WGS84.
 - pw: shared submission password, validated only by the server on POST.
 - Template placeholders must be replaced with actual values before use.
 - Opening the URL displays details; an authorized Submit action creates the
   activity and returns a readable JSON result. Repeated submissions must
   return the existing result rather than duplicate the activity.
